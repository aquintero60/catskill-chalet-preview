# The Catskill Chalet — design preview

Responsive static design proposal. Includes desktop, tablet and mobile layouts, stay selection and a demonstration date picker. No inquiries, reservations, payments, or emails are processed.

Images are generated illustrations from the original local demo, not photographs of the actual property. All actual property photography remains pending.

Published files: index.html, assets/cabin-exterior-demo.png, assets/cabin-interior-demo.png, .nojekyll, .gitignore and this README. The main application remains in a separate private repository. No credentials or environment files belong here.
